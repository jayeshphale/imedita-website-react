# imedita-website-react

Official enterprise web application for **I-MEDITA** — India's Premier Cisco Networking, CCNA, CCNP, CCIE, Multi-Vendor Firewalls, and Cyber Security Training Institute.

## 🚀 Key Features & Highlights

- **Hero Showcase Slider**: Interactive 4-slide enterprise showcase with certified instructors, career roadmap 3D topology, live physical datacenter rack engineering, and official exam vouchers.
- **Hardware-Accelerated Scroll Animations**: Fluid 60–120fps entrance reveals, wave-staggered card grids, and two-column glide transitions on mouse scroll.
- **Dedicated Demo Booking Section (`#request-demo`)**: High-converting lead generation section with country phone codes, training mode selection, live validation, and smooth anchor scrolling.
- **Live Batches & Timetables**: Searchable & categorized upcoming weekday/weekend batch schedules with direct enrollment triggers.
- **100% Guaranteed Vector Brand Logos**: 350+ placement partners and hiring alliances with instant retina rendering.
- **CCIE Faculty Architecture Deck**: In-depth faculty credentials and enterprise datacenter backgrounds.
- **Lenis Smooth Scroll Engine**: Integrated frictionless vertical scroll with hash navigation offset support.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler / Dev Server**: [Vite 8](https://vitejs.dev/)
- **Smooth Scrolling**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Modular CSS & Design Tokens with Responsive Breakpoints

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/jayeshphale/imedita-website-react.git

# Navigate to project directory
cd imedita-website-react

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
